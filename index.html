Seu próximo passo

Organizar pode ser simples.

  1. Use Nova tarefa para cadastrar o que precisa fazer.
  2. Escreva um título de 1 a 100 caracteres. A descrição é opcional e aceita até 500.
  3. Marque o quadrado ao lado da tarefa para concluir. Clique novamente para voltar a pendente.
  4. Use os filtros para ver pendências ou atividades concluídas.
  5. Use os ícones de lápis e lixeira para editar ou excluir.

As tarefas são salvas apenas neste navegador. Este protótipo começa com atividades de exemplo.
